## CONTEXT

This is DevLake project repository. Read README.md to get the context.

It allows to create plugins for data source you need in you project. See details at https://devlake.apache.org/docs/DeveloperManuals/PluginImplementation.

It supports two types of plugins: go and python.

## TASK

1. Create ClickUp data source python plugin for DevLake.
1.1. Read the details on how to create new pythin plugin at @backend\python.
1.2. The plugin shall only collect issues and incidents DevLake domain entites from ClickUp. 
1.3. Use https://developer.clickup.com/reference/gettasks ClickUp api to get ClickUp tasks and transform them to DevLake issues and incidents.
1.4. See @backend\plugins\webhook\api\issues.go as an example on how to create issues and incidents. (It is in go, so it needs to be transformed to Pydevlake approach to be used properly.)
1.5. Also you can check @backend\plugins\linear as an example on how to transform Data source specific entity to DevLake domain entity. (It is in go, so it needs to be transformed to Pydevlake approach to be used properly.)
1.6. Use incremental approach to collect issues. Sort by "created at" date local data and load data form clickup only after last "created at" date. Consider using one day overlapping window to reliably collect all the tasks from ClickUp. 
1.7. Add UI for the plugin at @config-ui\src\plugins\register.
1.8. Collected Incident Entities will be used to calulate DORA metrics and will be used together with GitLab deployments which are generated by GitLab plugin.

## Objective

Add a reusable `pydevlake/domain_layer/ticket.py` module exposing the `TICKET` /
incident domain SQLModel classes so any Python plugin (ClickUp being the first) can emit
them. This is the only task that touches `pydevlake` itself.

## Files

- **Create** `backend/python/pydevlake/pydevlake/domain_layer/ticket.py`
- **Modify** `backend/python/pydevlake/pydevlake/domain_layer/__init__.py` — add `ticket`
  to exports.

## Implementation notes

- Define exactly the classes and `__tablename__` values listed in tech design §1.5:
  `Board`, `Issue`, `BoardIssue`, `IssueAssignee`, `Incident`, `IncidentAssignee`, plus
  the type/status string constants.
- Mirror the existing `code.py` / `crossdomain.py` / `devops.py` modules for base-class
  usage (`DomainModel`, `DomainScope`, `NoPKModel`), import style, and the ASF license
  header.
- These map to **existing** Go-owned tables — declare `table=True` and the right
  `__tablename__`; do **not** add any migration here.

## Definition of Done

- Module imports cleanly; `from pydevlake.domain_layer import ticket` works.
- A small unit test (in `pydevlake`'s existing test location, mirroring how other domain
  modules are tested if at all) instantiates each model and asserts `__tablename__` and a
  couple of field assignments — enough to catch typos in column mapping.
- `azuredevops` and other plugins still import/build (no regression from the
  `__init__.py` change).

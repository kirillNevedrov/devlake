## Objective

Add a reusable `pydevlake/domain_layer/ticket.py` module exposing the `TICKET` /
incident domain SQLModel classes so any Python plugin (ClickUp being the first) can emit
them. This is the only task that touches `pydevlake` itself.

## Files

- **Create** `backend/python/pydevlake/pydevlake/domain_layer/ticket.py`
- **Modify** `backend/python/pydevlake/pydevlake/domain_layer/__init__.py` — add `ticket`
  to exports.

## Implementation notes

- Define exactly the classes and `__tablename__` values listed in tech design §1.5:
  `Board`, `Issue`, `BoardIssue`, `IssueAssignee`, `Incident`, `IncidentAssignee`, plus
  the type/status string constants.
- Mirror the existing `code.py` / `crossdomain.py` / `devops.py` modules for base-class
  usage (`DomainModel`, `DomainScope`, `NoPKModel`), import style, and the ASF license
  header.
- These map to **existing** Go-owned tables — declare `table=True` and the right
  `__tablename__`; do **not** add any migration here.

## Development progress

**Status:** DONE (2026-06-25)

### Implemented

- **Created** `backend/python/pydevlake/pydevlake/domain_layer/ticket.py` with exactly the
  classes, fields, defaults and `__tablename__` values from tech design §1.5:
  `Board` (`boards`, extends `DomainScope`), `Issue` (`issues`, `DomainModel`),
  `BoardIssue` (`board_issues`, `NoPKModel`, composite PK), `IssueAssignee`
  (`issue_assignees`, `NoPKModel`, composite PK), `Incident` (`incidents`, `DomainModel`),
  `IncidentAssignee` (`incident_assignees`, `NoPKModel`, composite PK). Plus type constants
  `BUG, REQUIREMENT, INCIDENT, TASK, SUBTASK` and status constants
  `TODO, IN_PROGRESS, DONE, OTHER`. ASF license header copied verbatim from `code.py`;
  import style (`from pydevlake.model import DomainModel, DomainScope, NoPKModel`) mirrors
  the existing modules. No migration added — these map to existing Go-owned tables.
- **Modified** `backend/python/pydevlake/pydevlake/domain_layer/__init__.py` — the file had
  no code (license header only). Added `__all__ = ["code", "crossdomain", "devops", "ticket"]`
  to declare the package's public submodules including the new `ticket`.
- **Created** test `backend/python/pydevlake/tests/ticket_test.py` (mirrors the existing
  `*_test.py` naming/location and ASF header used by `migration_test.py` etc.). It
  instantiates every model, asserts each `__tablename__`, sample field assignments, and the
  default values (`Issue.is_subtask == False`, `Incident.table == "boards"`) plus all string
  constants.

### Decisions / notes

- The package exports submodules by full path (e.g. `pydevlake.domain_layer.ticket`); the
  empty `__init__.py` does no re-exporting. "Add `ticket` to exports" was therefore satisfied
  by adding an `__all__` listing all domain submodules — minimal, non-breaking, and keeps the
  existing `import pydevlake.domain_layer.ticket as ticket` usage (already referenced in the
  README) working.

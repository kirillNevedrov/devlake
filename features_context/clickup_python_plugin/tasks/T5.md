**Status:** TODO
**Stage:** 2 · **Depends on:** T2

## Specs

- Tech design §1.9 "Migration Scripts" — [tech_design_spec.md](../tech_design_spec.md)

## Objective

Add `clickup/migrations.py` that creates the plugin's **tool tables only**, so a fresh
install provisions the ClickUp schema.

## Files

- **Create** `backend/python/plugins/clickup/clickup/migrations.py`.

## Implementation notes

- One `@migration(<ts>, name="initialize schemas for ClickUp")` calling
  `b.create_tables(...)` for `ClickUpConnection`, `ClickUpScopeConfig`, `ClickUpFolder`,
  `ClickUpTask` (the models from T2).
- **Must not** create domain tables (`issues`, `incidents`, `boards`, `board_issues`,
  `issue_assignees`, `incident_assignees`) — they are owned by Go core migrations.
- Follow the `azuredevops/migrations.py` convention: entities column as `json`,
  `connection_id`, `scope_config_id`; ASF header.

## Definition of Done

- `import clickup.migrations` works and the migration is discoverable by the framework.
- Verified (locally or by inspection against the azuredevops migration) that only the
  four tool tables are created and no domain table is touched.

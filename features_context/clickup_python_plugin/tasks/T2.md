## Objective

Create the `clickup` Python package directory and its data models so later tasks have a
buildable package to extend. Produces the connection, scope-config, tool-scope, and task
tool models.

### Deviations / notes

- `ClickUpTask.tags` and `.assignees` (`list[dict]`) required an explicit
  `sa_column=Column(JSON)` — SQLModel `table=True` rejects bare `list[dict]` fields with
  "no matching SQLAlchemy type". Tech-design §1.5 showed them as plain `list[dict] = []`;
  the JSON column is the SQLModel-compatible equivalent and does not change the schema
  intent.
- Imports mirror `azuredevops/models.py` (`from pydevlake.model import ToolScope,
  ToolModel, Connection`) rather than the §1.5 snippet's `from pydevlake import ...`;
  both resolve to the same classes.
- Added `README.md` (not listed in the task) so the poetry/uv build does not fail on the
  missing `readme` file. azuredevops has the same file.
- `build.sh` (uv.sh) targets `.venv/bin/python`, the POSIX layout; on this Windows host
  the venv is created at `.venv/Scripts/python.exe`, so the install/tests were run against
  that path directly. This is a pre-existing platform quirk of `uv.sh`, not a plugin issue.
- No migration, API, or stream logic added (reserved for T5 / later tasks). No existing
  plugin touched.
